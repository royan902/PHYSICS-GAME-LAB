# Kebutuhan Fase 1 — Development Environment Setup

Scope ini mengikuti instruksi pengguna terbaru dan menggantikan rencana scaffold pada Fase 0. Backlog implementasi dipindahkan ke [PHASE_2_REQUIREMENTS.md](PHASE_2_REQUIREMENTS.md).

- Audit Windows/PowerShell, Node LTS, npm/npx, Git, browser dan koneksi registry.
- Instal tools inti hanya jika belum memenuhi kebutuhan. Jangan mengubah identitas Git atau konfigurasi sistem yang tidak diperlukan.
- Pertahankan repository yang ada, buat ignore rules, serta checkpoint hanya jika user.name dan user.email sudah terkonfigurasi.
- Periksa empat skill project-scoped dan validasi struktur/metadata. Bedakan file valid dari discovery runtime.
- Periksa OpenAI Game Studio dan OpenAI Build Web Apps melalui katalog/marketplace resmi. Siapkan jika didukung; verifikasi status installed/enabled.
- Siapkan Playwright MCP resmi, uji koneksi nyata dan kemampuan WebGL/WASM browser. Tidak menambahkan MCP lain.
- Dokumentasikan versi, hasil, error/perbaikan, kebutuhan manual, serta kesiapan berikutnya pada PHASE_1_REPORT.md.
- Jangan membuat Next.js/game Billiard atau memasang library game. Dependency tooling diisolasi pada tools/environment dengan lockfile.

Gate selesai: seluruh kebutuhan yang tersedia ditangani, hasil aktual dan batas jelas, dan tidak ada perubahan sistem di luar kebutuhan. Integrasi yang membutuhkan login/izin manual dilaporkan tanpa mengklaim selesai. Status akhir PASS/PARTIAL/FAIL harus sesuai bukti.
