# Asset provenance

Kelima ilustrasi SVG dibuat orisinal untuk Physics Game Lab pada Fase 2, tanpa mengambil gambar atau asset dari referensi pihak ketiga. Pemilik proyek dapat memakai dan mengubahnya bersama kode proyek. Bukan screenshot gameplay.

`newton-first-law.png`, `newton-second-law.png`, dan `newton-third-law.png` adalah screenshot scene game Newton dari file HTML yang diberikan pengguna, direkam setelah pemisahan tanpa HUD pada 23 November 2026. Geometri dan material mengikuti sumber pengguna; bukan foto pihak ketiga atau gambar hasil generasi AI.
